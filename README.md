# Lilka Stream Deck

A macro pad (Stream Deck alternative) based on the ESP32-S3 "Lilka" console. 
Features native USB HID support, MicroSD icon storage, and a cross-platform desktop companion app.

## Structure
- `/firmware` - ESP32-S3 C++ code (PlatformIO).
- `/desktop` - Cross-platform C# configuration app (Avalonia UI).
- `/docs` - Pinout schemas and documentation.
